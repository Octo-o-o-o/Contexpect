Contexpect · 前端重构提案 · 2026-09-10

三套设计方向，请挑一套

三个 demo 均为自包含单文件 HTML，使用同一份 fixture 数据、同一个 canonical 页面（Doctor 首屏），仅视觉语言与交互密度不同。点击卡片在新页打开。
方案 A

Refined Clinical

精密仪器 · 浅色进化版

在现有设计系统上演进到顶级工具质感：暖纸画布 + 墨蓝导航，分组信息架构，状态带与证据链更克制精确。改动最小、落地最快、语义继承最完整。

 方案 B

Dark Instrument

暗夜观测台 · 开发者控制台

深色优先的观测仪器：发光语义色、等宽字体数据、⌘K 命令栏、图标轨道导航。密度最高、最「酷」，适合重度开发者心智；但实现成本与可读性权衡最大。

 方案 C

Audit Ledger

审计账簿 · 编辑文档风

把每个 Receipt 当作一份「诊断纪要」：衬线标题、发丝线、编号条目 + 右侧批注栏。最优雅、最差异化，与「凭据/核对」的产品语义天然契合；信息密度最低。
三套方案共同守住的红线（来自项目冻结合同）：Unknown ≠ severity（紫色独立通道）· 无统一健康分 · 六 facet 不合并 · Static resolution 永不标 Verified · Indeterminate 时 Treatment 锁定 · 状态三通道（文字+图标+颜色）· 4/9/5 coverage 明确标注为 fixture。
也可以混搭：例如 A 的信息架构 + C 的排版 或 B 的深色 + A 的组件密度。
